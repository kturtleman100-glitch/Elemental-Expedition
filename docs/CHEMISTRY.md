# 이 게임의 화학

목표는 하나다. **놀다 보면 화학이 남는 것.**
그래서 틀린 값이 들어가면 재미가 아니라 오개념을 가르치게 된다.
화학 데이터를 고치기 전에 이 문서를 읽는다.

---

## 1. 고치면 반드시 검사한다

```
node tools/check-chemistry.mjs
```

`tools/chem-reference.mjs` 의 기준값(IUPAC 원자량 2021, 폴링 전기음성도)과
게임 데이터를 대조한다. 다섯 가지를 본다.

| 검사 | 무엇을 |
|---|---|
| 원소 수치 | 원자번호·원자량·전기음성도·녹는점·끓는점·족 분류 |
| 전투 유형 | 금속=무기형, 비금속=마법형 규칙을 어기면 **이유가 적혀 있는가** |
| 화합물 | 화학식을 분해한 결과가 `needs` 와 맞는가, 그 원소가 게임에 있는가 |
| 인연 | 가리키는 원소가 실제로 존재하는가 |
| 학습 커버리지 | 족마다 몇 종이 있는가, 어떤 결합을 다루는가 |

결과는 세 등급이다.

- **오류** — 사실이 틀렸다. 반드시 고친다 (`check.sh` 가 실패한다)
- **학습 공백** — 화학은 맞지만 플레이로 도달할 수 없다
- **각색** — 게임적 선택. 의도했다면 둔다

현재: **오류 0 · 공백 1 · 각색 0**

## 2. 검사기가 실제로 잡아낸 것

도구를 만든 값어치가 여기 있다.

| 잡아낸 것 | 무엇이 문제였나 |
|---|---|
| 폴로늄 원자량 210 → **209** | Po-210이 유명하지만 가장 안정한 것은 반감기 125년의 Po-209 |
| 테크네튬 99 → **98**, 끓는점 4877 → **4265** | 그냥 틀린 값 |
| 납·비스무트가 **준금속**으로 분류 | 둘 다 명백한 금속(전이후 금속). `POST_TRANSITION` 족을 새로 뒀다 |
| **플루오린·수소·소듐이 원소 목록에 없었다** | NaCl·H₂O·CaF₂가 영원히 제작 불가였다. 세 원소를 추가 |
| 알칼리 금속이 소듐 하나뿐 | "1족은 아래로 갈수록 전자를 쉽게 내준다"를 비교할 대상이 없다 → 포타슘 추가 |

## 3. 게임 규칙이 곧 화학이다

임의로 정한 수치가 거의 없다. 규칙이 실제 성질에서 나오면 플레이어가
외우지 않고 **추측**할 수 있다.

### 상성 — 폴링 전기음성도

```
피해 배율 = 1 + (공격자 전기음성도 − 방어자 전기음성도) × 0.35
```

플루오린(3.98)이 소듐(0.93)을 때리면 ×2.07. 실제로 격렬히 반응하는 조합이다.
비활성 기체는 전기음성도가 **정의되지 않으므로** 예외로 ×0.4를 준다 —
빈칸이 아니라 정의할 수 없다는 뜻이고, 그게 곧 "반응하지 않는다"이다.

### 전자(e⁻) — MP를 대체한다

| 역할 | 누가 | 왜 |
|---|---|---|
| 방출형 | 금속 | 바깥 전자를 내주고 안정해진다 |
| 탈취형 | 비금속·할로겐 | 전자를 받아야 옥텟이 찬다 |
| 무반응 | 비활성 기체 | 이미 차 있어 주고받을 것이 없다 |

### 전투 유형

금속은 실체가 있어 벼려서 무기가 되고(무기형), 기체·비금속은 형체가 없어
힘 자체로 작용한다(마법형). 준금속은 경계에 있으므로 하이브리드다.

**규칙을 어기는 다섯**(브로민·마그네슘·베릴륨·수은·비소)에는 `exception`
필드로 이유를 적는다. 설명 없이 두면 "마그네슘은 비금속인가 보다"라고
잘못 배운다. **검사기가 이유 없는 예외를 오류로 잡는다.**

## 4. 데이터를 추가할 때

### 원소

`src/data/elements.js`. 수치는 실제 값을 쓰고, `tools/chem-reference.mjs` 의
`REF` 에도 같은 원소를 넣어야 검사가 돈다.

```js
{
  id: "k", z: 19, sym: "K", ko: "포타슘", en: "Potassium",
  family: FAMILY.ALKALI, combat: COMBAT.STRIKER, silhouette: "bulky",
  mass: 39.1, electroneg: 0.82, melt: 63.5, boil: 759,
  faction: "neutral", role: "...",
  bio: "...", quote: "...",
  bonds: ["na", "ar", "cl"],
  colors: { main: ..., sub: ..., accent: ..., hair: ... },
  // 족 규칙(금속=무기형)을 어길 때만
  exception: "왜 어기는지",
}
```

### 화합물

`src/data/bonds.js`. **실재하는 물질만** 넣고, `chem` 에 결합 종류와
그 물질이 알려주는 화학을 적는다.

```js
{
  id: "ice", name: "얼음", formula: "H₂O", needs: ["h", "o"],
  desc: "...",
  effect: { kind: "glide", speed: 2.1, duration: 9, note: "..." },
  chem: {
    bond: "극성 공유 결합 + 분자 사이의 수소 결합",
    fact: "...",
  },
}
```

`tools/chem-reference.mjs` 의 `REAL_COMPOUNDS` 에도 넣는다.
필요한 원소가 게임에 없으면 검사가 "제작 불가"로 잡는다.

**효과는 그 물질의 실제 성질에서 끌어낸다.** 이게 이 게임의 핵심 규칙이다.

| 화합물 | 효과 | 근거 |
|---|---|---|
| 소금 NaCl | 직선 관통 | 이온 결정이 단단하다 |
| 물 H₂O | 알칼리 금속에 연쇄 폭발 | 실제로 격렬히 반응한다 |
| 얼음 H₂O | 15초간 이동 속도 2.1배 | 마찰이 거의 없다 |
| 녹 Fe₂O₃ | 방어 −40% | 금속을 삭힌다 |
| 이산화탄소 CO₂ | 광역 질식 | 공기보다 무거워 낮게 깔린다 |
| 방연석 PbS | 피해 절반 | 납은 밀도가 높아 방사선을 막는다 |
| 브로민화은 AgBr | 직전 것을 한 번 더 | 빛을 기억한다 (필름의 원리) |

### 바이옴

`src/world/Biome.js`. 땅도 화학에서 나온다.
`teaches` 에 적은 한 줄이 그 땅을 처음 밟을 때 뜬다.

## 5. 플레이어가 화학을 만나는 지점

| 어디서 | 무엇을 |
|---|---|
| 도감 `K` | 원소의 실제 수치 + **족 해설**(성질 / 전자 배치로 본 이유 / 게임 규칙 / 비교해 볼 수치) |
| 도감 `K` | 족 규칙을 어기는 원소의 이유 |
| 인벤토리 `E` | 화합물의 결합 종류와 화학. CaF₂의 아래 첨자가 왜 2인지까지 |
| 전투 | 상성 배율이 화면에 뜬다 ("×2.07 격렬 반응!") |
| 탐험 | 새 바이옴에 들어서면 그 땅의 화학이 한 번 |

족 해설이 네 칸인 이유는 마지막 칸 때문이다.

> **할로겐** — 바깥 전자가 일곱이라 하나만 모자라다 → 그래서 뭐든 뺏으려 든다
> → **그래서 게임에서 탈취형이다** → 그래서 염소가 아르곤을 노린다

설정과 전투 규칙과 실제 화학이 같은 한 줄로 이어진다.
방금 전투에서 겪은 일이 왜 그랬는지 알게 될 때 지식이 붙는다.

몰리브데넘 ← Ti, Tc            (2곳)
헬륨 ← Ne, Ar                  (2곳)

# 캐릭터 모델 폴더

VRoid Studio에서 내보낸 `.vrm` 파일을 여기에 넣는다.

## 파일 이름 규칙

`src/data/elements.js`의 `id` 값을 그대로 쓴다. 소문자.

| 원소 | 파일명 |
|---|---|
| 플레이어 119번 | `uue.vrm` |
| 칼슘 (토룡마을 촌장) | `ca.vrm` |
| 탄소 (학교 교장) | `c.vrm` |
| 규소 (예언가) | `si.vrm` |
| 인 (택배 기사) | `p.vrm` |
| 철 (군단 대장) | `fe.vrm` |
| 마그네슘 (세계수) | `mg.vrm` |
| 우라늄 | `u.vrm` |
| 염소 (주적) | `cl.vrm` |
| 폴로늄 (최종 보스) | `po.vrm` |

전체 목록은 `src/data/elements.js`의 `ELEMENTS` 배열 참조.

## 규칙

- 형식은 **VRM 1.0** 으로 통일한다
- 내보내기 설정: 메시 결합 켜기, 텍스처 아틀라스 2048
- 파일이 없는 원소는 `CharacterBuilder`의 절차적 생성으로 자동 대체된다.
  즉 **한 명도 없어도 게임은 정상 동작한다**

# Elemental Expedition

아스티온 대륙을 무대로 한 원소 소재 3D RPG. Three.js(WebGL) 기반, 빌드 도구 없이 CDN + importmap으로 동작합니다.

## 실행 방법

`index.html`을 브라우저로 직접 열면 `file://` 프로토콜에서 ES 모듈이 CORS로 막힐 수 있습니다. 로컬 서버로 띄우세요.

```powershell
npx serve .
```

그 다음 안내되는 주소(보통 `http://localhost:3000`)로 접속합니다.

### 같은 와이파이의 휴대폰에서 확인

```powershell
npx serve . --host 0.0.0.0
```

PC의 로컬 IP(예: `192.168.0.12`)를 확인한 뒤 휴대폰 브라우저에서 `http://192.168.0.12:3000` 으로 접속합니다.

### 배포된 주소로 확인

`main` 브랜치에 push하면 Vercel이 자동으로 배포합니다. 배포 주소는 `https://<프로젝트>.vercel.app` 형태입니다.

## 개발 상태

`.claude/plans` 계획서 기준 9단계 중 1단계(움직이는 3D 월드) 진행 중입니다.

## 참고자료 안내

`참고자료/` 폴더는 책을 촬영한 개인 스캔 이미지이며 `.gitignore`로 제외되어 저장소에 올라가지 않습니다. 게임 속 세계관·캐릭터 설정은 이 자료를 참고해 만들었으나, 일러스트는 그대로 사용하지 않고 원본 3D 모델로 새로 제작합니다.

## 캐시 정책

`vercel.json`이 모든 파일에 `no-cache`를 건다. 브라우저는 여전히 캐시하지만
매번 서버에 물어보고(대개 304로 본문 없이 끝난다) 최신인지 확인한다.

예전에는 `/src/`에 `max-age=3600`을 걸어 뒀는데, 빌드 도구가 없어 파일 이름에
해시가 붙지 않으므로 배포 직후 한 시간 동안 **옛 모듈과 새 모듈이 섞여** 들어왔다.
모듈 하나만 옛것이어도 import가 어긋나 로딩이 0%에서 멈춘다.

개발 서버는 `serve.json`이 `no-store`를 보내 아예 캐시하지 않는다.
